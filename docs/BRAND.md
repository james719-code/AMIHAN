# FieldWise branding

The mark pairs Mayon’s cone with curved field rows and a rice-gold sun. The FieldWise wordmark stays as live text next to the mark in the explorer header. The same mark appears in the browser tab.

| Color | Hex | Use |
| --- | --- | --- |
| Forest green | `#183A2D` | Masthead, headings, active controls, and map markers |
| Rice gold | `#F1CD73` | Wordmark accent and selected map marker |
| Coastal blue | `#266780` | Rainfall and keyboard focus |
| Clay | `#A95337` | Mean temperature, with deep clay for maximum temperature |
| Warm paper | `#F6F4EB` | Page background |
| Soft white | `#FAF9F6` | Card, sidebar, and workspace surface |

The interface uses a darker gold for solar radiation and for text in gold-tinted status panels. Chart titles, units, and the map legend carry the labels alongside the colors.

Two other directions for the identity are coastal blue `#1D4F63` with sand `#F4E9D2` for a mapping emphasis, and terracotta `#884733` with olive `#606B43` for a soil and farming emphasis.
